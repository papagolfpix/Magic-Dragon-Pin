MAGIC DRAGON PIN v0.9.85 — SUNDAY SUGGESTED DELIVERY DOCKETS

Primary target: Pin on iPhone.

New workflow
- Saving a verified Sunday invoice now creates one Suggested Delivery per reconciled branch.
- Only products with units sold > 0 are included.
- Suggested quantity equals units sold that week.
- Suggestions are stored separately from real delivery dockets and DO NOT count in reconciliation or delivery totals.
- Delivery Dockets shows SUGGESTED entries above normal saved dockets.
- Open a suggestion, tap Review / Edit Suggestion, change anything required, then Save as Permanent Docket.
- Only after that save does the suggestion become a normal delivery docket.
- Dismiss Suggestion removes the draft without affecting stock/reconciliation.

Safety
- Existing invoice, payment, reconciliation, delivery and backup logic is unchanged.
- A converted suggestion records its source Sunday date on the permanent docket so refreshing the same invoice does not create a duplicate suggestion.

Test
1. Complete reconciliation and save/refresh a verified Sunday invoice.
2. Open Delivery Dockets.
3. Confirm one SUGGESTED entry appears per branch that had sales.
4. Open it and verify quantities equal that Sunday report's units sold.
5. Review / Edit Suggestion.
6. Change a quantity, date or note if desired.
7. Save as Permanent Docket.
8. Confirm the suggestion disappears and a normal saved docket appears.
