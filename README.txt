MAGIC DRAGON PIN v0.9.80 — DRAGON HOME HOTSPOT

Primary target: iPhone.

Change
- The dragon area on the left side of the app header is now an invisible Home/Dashboard button.
- Tapping the dragon returns directly to the Dashboard from any normal app screen where the header is visible.
- The hotspot has no visible border, icon, label, or overlay.
- Existing Menu and per-screen navigation remain intact for now while this behaviour is tested.
- This creates a consistent escape route from screens such as Delivery Dockets without adding more visible navigation clutter.
- Retains all v0.9.79 invoice-management and iPhone no-focus-zoom fixes.

Quick test
1. Open Delivery Dockets or Records.
2. Tap the dragon image in the top-left of the header.
3. Confirm the app returns to Dashboard immediately.
4. Repeat from several other screens.
5. Confirm the Menu button still works normally.
