MAGIC DRAGON PIN v0.3.1 — iPHONE TEST / DEPLOYMENT BUILD

IMPORTANT
ChatGPT's attachment preview is not the deployment environment for this JavaScript app.
Upload the CONTENTS of this folder/ZIP to a static HTTPS host (for example GitHub Pages,
Cloudflare Pages or Netlify), then open that HTTPS address in Safari.

iPHONE INSTALL
1. Open the deployed HTTPS address in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
4. Open Magic Dragon Pin from the new Home Screen icon.
