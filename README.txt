MAGIC DRAGON PIN v0.5.1 — EXCEL IMPORT UI REFINEMENT

Changes:
- Branch and Sunday date selectors removed from the primary Excel workflow.
- Excel imports auto-detect branch and check date from each workbook.
- Branch/date controls remain available only for screenshot OCR fallback.
- Excel file selection now shows an immediate highlighted confirmation card BEFORE import.
- The confirmation card lists every selected filename.
- One or multiple Excel files remain supported.
- Existing archive naming, master workbook export, and OCR fallback retained.
